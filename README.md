This is a solution to question 3 of the Fall 2012 programming contest at UC Berkeley which was given as an course project. 
Here is a link to the provided problems https://people.eecs.berkeley.edu/~hilfingr/programming-contest/f2012-contest.pdf.
The solution uses backtracking and all its optimizations 
The code uses a lot of data structures to speed up and track the position of magnets, algorithm wise the code uses MRV, propagation tables, forward checking and AC3 optimizations.
